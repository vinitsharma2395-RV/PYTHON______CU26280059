PYTHON PROGRAMMING LAB SHEET 07 - FILE HANDLING

CONTENTS
- 1.py to 20.py: Text-file exercises (in question order).
- 21.py to 30.py: CSV exercises (in question order).

RUN A PROGRAM
From the workspace folder, run a file with Python, for example:
    python "LABSHEET 7/1.py"

Python's standard library is enough; no packages need to be installed. Each
program saves its example files in this LABSHEET 7 folder, regardless of the
terminal's current directory.

NOTES
- Run one question at a time. Several exercises intentionally reuse names such
  as sample.txt and students.csv, and will replace those example files.
- Programs that ask for input wait for a response in the terminal.
- Q07 stops accepting lines when you enter END.
